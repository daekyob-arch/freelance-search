# 프리랜서 검색 도우미

**👉 https://daekyob-arch.github.io/freelance-search/**

검색어와 제외 검색어를 넣으면 프리랜서 사이트(위시켓 · 크몽 · 이랜서 · 원티드 긱스 · 프리모아 · OKKY Jobs)의
검색 결과를 브라우저 탭으로 바로 엽니다.

- 사이트에 자동으로 요청하지 않고 **링크만 만듭니다** — 사람이 직접 눌러서 보는 방식
- 검색어 규칙: 공백 = 모든 단어(AND), 쉼표 = 또는(OR)
- 제외 검색어는 구글 사이트 검색(`site:주소 검색어 -제외어`)에 적용
- 입력한 검색어는 브라우저 안에서만 처리되고 어디에도 전송·저장되지 않습니다 (마지막 입력값만 내 브라우저에 기억)
- 파일 하나(`index.html`)로 동작하며 외부 라이브러리를 쓰지 않습니다
